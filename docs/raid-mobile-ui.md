# スマホ向けレイドUI

対象は `/battle/raid` と `/battle/raid?sync=local`。ゲームの計算・入力受付・通信APIは共通の既存処理を使用し、表示を変更しています。

## レイアウトと表示

- 赤 `#E8223C`、暗赤 `#870B20`、白系 `#F7F8FA`、文字 `#17171C`、補助文字 `#88818C`。全体の背景は提供画像 `public/raid-mobile-background.png` を縦横比を維持して画面全体に表示し、上部中央を基準に余白なく配置します。情報パネルは白系で読みやすさを保ち、勝利時にゴールドを使用します。
- スマホには敵モデルを表示しません。上部にはボス名・HP・ラウンド・参加人数・接続状態を小さくまとめます。同期値は `visibleLocalRaid` の公開段階を維持します。
- 描画はスマホ向けの解像度と約30fpsに抑え、タブ非表示時は描画しません。動きを減らす設定では静止表示にします。
- 自分のパートナーを大きな正面向き3Dモデルで表示し、名前の切替・体験バッジを上、自分のHPを直下に置きます。`PartnerScene` / `raid-partner-arena.ts` に既存の原画をもとにした種類別の仮3Dモデル（FOREST / THUNDER / FLAME / AQUA / LEGEND）を実装しています。正式なモデル素材はまだありません。カメラは正面に固定し、自動回転しません。WebGL非対応・コンテキスト喪失時は選択キャラの `CharacterArt` へ切り替えます。被弾・回復時にもWebGLを作り直さず、既存の反動とHP同期を維持します。
- `RaidHpGauge` は一本のSVGバー。左右を六角形の頂点にし、連続した背景・塗りつぶしの上へくの字の境界線を重ねます。独立したセル間の隙間はなく、数値は横に表示します。残り25%以下でのみ警告色と控えめな明滅を使い、動きを減らす設定では明滅しません。
- 攻撃／回復は2択の切替。手は3つの六角形ボタン。タップ領域を44px以上に保ち、選択は赤のグラデーションと約180msの反応で示します。
- パートナー背景には属性色の六角形台座と光の柱を配置します。属性・学科はキャラクター情報から表示し、「パートナー変更」の選択メニューと左右の矢印で同じ切替処理を呼び出します。送信中・演出中などの切替制限も共通です。選択中の行動と手はチェック、白い輪郭、控えめな影で強調し、送信ボタンは二段のラベルを持つ赤い六角形にしています。
- 効果の目安は現在の行動・基本値・HP上限から表示します。ボスの未公開の手を推測しません。複数人でのオーバーキル配分などにより確定値は変わります。
- 送信後はサーバーが受理した自分の行動・手を確認でき、再読み込みでも復元します。じゃんけんの公開・命中時のHP更新・次の受付への自動復帰は従来の同期処理を維持します。
- 討伐は画面上のボスHPが0になった時点で切り替えます。コマンド送信を非表示にし、そのラウンドの個人結果（勝敗・倍率・効果量・反撃）を専用パネルへ表示します。個人結果がない場合は「—」で示します。次のレイドは会場側で開始し、スマホからはホームへ戻れます。

375〜430px幅を優先し、短い縦画面でもボス情報を小さくまとめ、自分のモデルとコマンドの領域を確保します。横向きとPCでは左右に配置します。Safe Areaを考慮し、極端に高さが足りない縦画面では内容を縦スクロールできます。下部の3項目のナビゲーションは維持します。

## 確認方法

```powershell
npm.cmd run typecheck
npm.cmd run test:e2e -- tests/e2e/battle.spec.ts tests/e2e/local-raid.spec.ts tests/e2e/raid-mobile-design.spec.ts --project=chromium
```

Safariと同じWebKitエンジンの確認は別設定です。実機iPhoneでの確認とは区別してください。

```powershell
npx.cmd playwright install webkit
npm.cmd run test:e2e -- --config=playwright.webkit.config.ts
```

操作・HPや保存データの維持・自動復帰・非WebGL・動きを減らす設定・小型画面・複数人の同期・討伐成功時の送信抑止と結果保持を検証します。正式なイベントや報酬データは追加しません。
