# 会場レイドスクリーン UI

`/raid/screen` は会場投影用の独立した16:9 UIプレビュー。ログイン・DB接続なしで表示できます。既存の参加者用 `/battle/raid` とは別の画面です。

実際のスマホと同期する開発用モードは `/raid/screen?sync=local` と `/battle/raid?sync=local` です。LAN起動・実機URL・簡易戦闘ルールは [ローカル同期の手順](local-raid-sync.md) を参照してください。以下は通常の表示プレビューの説明です。

- 既存の赤白ハニカム背景、立体のキング・アクアとWebGL非対応時のイラストを再利用。
- ボスHP、参加人数・攻撃と自己回復の入力状況、ターン、攻撃予告、入力残り時間を表示。
- 縦横比を保って画面内に収め、16:9以外の表示領域には余白を設けます。
- 右下の「表示設定」で、行動選択・じゃんけん・自己回復・総攻撃・ボス攻撃・討伐成功を切り替えます。
- 自動再生は各場面を順番に繰り返す表示デモです。初期状態では停止しており、設定から一時停止・リセットできます。
- 右下の全画面ボタンで投影時に全画面表示へ切り替えます。

人数・ボスHP・行動・ターン・時間は `src/lib/raid-screen-preview.ts` の仮データ。画面は実際の参加受付、スマホ操作、管理者認証、サーバーでの戦闘計算、通信同期、報酬保存には接続していません。自動再生の開始操作はレイドの開催操作ではありません。

## 決定した行動と倍率

スマホは「攻撃」「回復」の2択。攻撃対象はボス、回復対象は自分です。じゃんけんは勝ち2倍・あいこ1倍・負け0.5倍で、攻撃量と自己回復量の両方に適用します。共通ルールは `src/lib/raid-rps.ts` で管理します。旧資料の3ロール・防御・必殺コマンドは現在のレイドUIには表示しません。CPU対戦のルールは別です。

`/battle/raid` の「じゃんけんで試す」から手を選択すると、ブラウザ内のランダムなボスの手と比較して倍率と効果量の例を表示します。基本攻撃50・基本回復30は仮値。HP・所持データは変更せず、回復は他人に適用しません。本番ではボスの手と結果をサーバー側で確定する必要があります。

後続の同期実装ではプレビューデータをサーバーが確定したレイド状態に置き換え、管理画面での開始操作から受付締切・カウントダウン・戦闘への切替を行います。
