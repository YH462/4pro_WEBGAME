# OpeningVoice と4場面の同期

ユーザー提供の `music/OpeningVoice.mp3` を `public/music/OpeningVoice.mp3` に同じ内容で配置し、以前の合成音声から差し替えた。元ファイルと配信用ファイルのSHA-256一致を確認した。

| 経過時間 | 表示 |
| --- | --- |
| 0〜16秒未満 | ① 参加案内 |
| 16〜26秒未満 | ② 攻撃・回復 |
| 26〜38秒未満 | ③ じゃんけん |
| 38〜49秒未満 | ④ 送信完了・開始案内 |
| 49秒 | 最初の10秒の入力受付を自動開始 |

①はユーザー指定の0〜15秒の後も②の開始まで保持し、空白を挟まない。実音源はブラウザでのデコード結果が48.927333秒で、48秒以降にも発声があるため、末尾が切れないよう説明とバトル開始を49秒に設定した。音声を伸縮・切り取りはしていない。

開始時刻・説明時間・音源URLは `src/lib/raid-tutorial-timing.ts` で共通管理する。サーバーの説明期限、スマホの案内、スクリーンの画像・強調枠、途中再生のオフセットに同じ設定を使う。バトル開始後30秒間の途中参加は維持し、開始ボタンから79秒で新規参加を締め切る。

説明音声は従来どおり初期状態オフ。操作バーの「説明音声」をオンにしてから「ルール説明を開始（49秒）」を押す。読み込みや音声再生に失敗しても説明とゲームの進行は継続する。

検証結果：

- 単体テスト212件、型チェック、本番ビルドが成功。
- 専用DBと本番ビルドの関連ブラウザ検証6件が成功。実時間での49秒の説明と開始後30秒の参加受付、場面境界の前後、MP3の実デコードと途中再開、BGM音量調整、再読み込み、画面サイズ別の操作欄を確認した。
- `output/raid-opening-20261101/` に場面ごとの確認画像を保存した。

本番サーバーへの反映は未実施。DBスキーマ移行は不要。
