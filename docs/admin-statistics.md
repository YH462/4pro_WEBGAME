# 管理者用統計ダッシュボード

`/admin/statistics` で、現在の `EVENT_ID` の統計・ランキングを確認する。キャラクター管理のヘッダーに「統計・CSV」へのリンクを追加した。ページ・JSON・CSV・ZIPのすべてに管理者ログインが必要で、ゲストセッションでは取得できない。ログイン前にページを開いた場合は、認証後に統計へ戻る。

## 表示と更新

参加登録数、収集参加者数、4学科達成人数／率、完了レイドに参加した人数、完了戦闘数、討伐成功率を表示する。登録数は端末・セッションに基づく参加者登録の数であり、実来場人数や現在のオンライン人数ではない。

時間帯別の登録グラフは日本時間の0〜23時で、表示日だけを切り替えられる。ページ全体とCSVの集計範囲は現イベント全期間。キャラ別獲得人数、成功／全滅、成功した戦闘の平均ターンを表示し、「学科・レイドの詳しい統計」から学科別人数・参加人数別成績・キャラ使用数を確認できる。

ランキングは収集数・討伐成功数・討伐ポイントの3種類。所持キャラは自動解放の4プロを含め、体験使用を含めない。ポイントは報酬台帳の実値を合計する。同点は1位・1位・3位の方式で、0の人はランキングに出さず、参加者CSVには含める。同名と名前未入力の人は表示用識別子で区別する。

5秒ごとに更新し、非表示タブでは取得を止める。通信失敗時は最後の正常な統計を維持し、最終更新時刻を残す。401を受けた場合は参加者情報を隠し、ログインへのリンクを表示する。初期取得中は数値を「—」とし、実測0件と区別する。

## CSV出力

「CSV出力」で全5種類をZIPへまとめるか、個別CSVを選ぶ。

- `summary.csv`：概要の指標
- `participants.csv`：参加者ID・ニックネーム・登録日時・収集数・学科数・戦績・ポイント・順位
- `collections.csv`：誰がどのキャラをいつ獲得したか
- `raids.csv`：完了した戦闘ごとの結果・人数・ターン数
- `raid-participants.csv`：各戦闘の参加者・当時のキャラ名・結果・実際の付与ポイント

ファイル名にイベントIDと日本時間の出力日時を付け、各CSVにも対象イベントと共通の出力日時を入れる。ZIPの5ファイルは同じDB読み取りスナップショットから生成する。UTF-8 BOM付き・CRLF改行で、引用符・カンマ・改行と、文字列セルの数式実行対策に対応する。DBのニックネーム自体は変えない。

認証情報、タグのトークン、モデル本体は出力しない。CSVは分析用で、削除済みアカウントを復元するDBバックアップではない。デモ終了後に初期化する場合は、先にCSV一式とDBバックアップを保存する。初期化の操作はこの画面には設けていない。

## 実装とデータの扱い

`event-statistics-query.ts` がイベントに属する必要な列をRepeatable Readトランザクションで読み、`event-statistics.ts` が共通集計を行う。参加者別の `RaidResult` は `roomId` ごとにまとめ、20人の1戦を20戦と数えない。統計を読むだけで報酬付与・部屋作成・戦闘進行・参加者変更は行わない。終了済みイベントも削除前なら参照できる。

`/api/admin/statistics` と `/api/admin/statistics/export?file=all` を使用する。イベントIDをリクエストから切り替えることはできない。応答は `private, no-store`。新しい依存パッケージやDBマイグレーションは不要。
