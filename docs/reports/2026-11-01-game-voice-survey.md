# バトル中の音声と高専祭アンケート欄

ユーザー提供の `music/GameVoice1.mp3`〜`GameVoice5.mp3` を、同一内容で `public/music/` に配置。実ブラウザでのデコード時間は順に10.371秒、9.639秒、8.438秒、6.426秒、16.118秒。

- 開始前のOpeningVoice・49秒の説明を維持し、バトル開始15秒後にGameVoice1を再生。
- 公開されたボスHPが半分／4分の1に達したらGameVoice2／3、勝利演出でGameVoice4、4の実際の再生終了から3秒後にGameVoice5。
- 同一バトルで繰り返さず、重複時は新しい体力段階・勝利を優先。既に体力案内に進んだ場合は15秒の倍率案内を省く。オフ・非表示中の案内を後から再生しない。
- 既存の説明音声ボタンを共用。再生中のBGMを通常の30%にし、音声終了／3秒の間は戻す。消音・リセット・非表示・離脱ではアンケート予約も取り消す。
- ホーム上部に高専祭アンケート欄を追加。`.env` の `KOSEN_SURVEY_URL` にフォームURLを設定し、サーバー再起動で有効にする。現在のローカル設定は空欄のため準備中。設定済みなら新しいタブで外部フォームへ移動。

検証：

- 単体テスト223件、TypeScript、通常のTurbopack本番ビルドが成功。
- 最初のサンドボックス内ビルドで内部通信エラーが発生したが、ビルド専用Turbopackキャッシュを除去して再検証すると成功。開発サーバーのキャッシュ・データは変更していない。
- 専用DB／ローカルサーバーで関連ブラウザテスト3件が成功。既存説明音声の位置復帰、実際の5音源と順序、BGM、勝利音声終了から3秒の間、アンケート設定済みリンクの新規タブ遷移を確認。
- 使用中のlocalhost:3000でもホームの未設定表示を375×667・390×844・844×390・1366×768で撮影して確認。5音源の取得・デコードと説明音声の有効化を確認。使用中のレイド状態を変更するAPI操作は行っていない。

- 追加の表示修正として、送信後のスマホ下部を「参加完了！」から「送信完了！」に切り替え、説明用の `sent.jpg` を再撮影。参加直後・送信後・次ラウンドでの切り替えを実ブラウザで確認し、型チェックも成功。説明画像の強調座標は変更なし。

実装・検証はローカルで実施。本番環境へのデプロイは行っていない。専用検証DBは終了し、ユーザーの開発サーバーは起動状態を維持。
