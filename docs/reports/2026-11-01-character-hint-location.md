# ヒント画面の場所名

管理画面に「場所名」を追加し、ヒント画面では既存DBのキャラ名の下へピンのアイコンと場所名を表示する。写真1枚・写真2枚の両方で共通。未設定の場合は「場所は準備中です」と表示する。

`202611010002_character_hint_location` で `CharacterLocationHint.location`（VARCHAR 200、空文字初期値）を追加する。既存の補足文・画像は保持し、場所名だけを変更できる。200文字以内の1行として検証し、改行や制御文字を拒否する。旧フォームが場所名を送らない場合は保存済みの場所名を維持する。

関連単体テスト13件、型チェックを含む本番ビルド、ブラウザ4シナリオが成功。管理画面での登録と再読み込み、公開側でのキャラ名・場所名の同時表示、旧フォームの互換性、場所変更、既存画像の維持と差し替え、還暦だるまの写真1枚での表示、小さい画面の配置を確認した。

ローカルDBと専用検証DBへ追加移行を適用済み。開発サーバーを止めてからビルド・検証し、生成済みの開発キャッシュを作り直してLAN対応設定で再起動する。キャラ名・能力値や実際のヒント素材は変更していない。本番への反映は未実施。
