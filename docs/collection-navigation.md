# キャラ詳細の前後移動

`/collection/[id]` の詳細パネルをスマホで左へスワイプすると次のNo.、右へスワイプすると前のNo.へ移動する。上部の左右の矢印からも同じ移動ができる。

- 前後の対象はDBの `Character.sortOrder` から取得する。IDやNo.の連番を仮定せず、欠番がある場合もその前後の登録キャラへ進む。
- 先頭と末尾は循環させず、その方向の矢印を無効にする。未獲得・4プロ・追加キャラも一覧と同じNo.順に含める。
- スワイプはタッチ入力のみ。横移動が48〜80px以上で縦移動の1.5倍を超え、1.2秒以内で終了した場合に判定する。画面端20pxはブラウザの戻る操作を優先する。
- 縦方向のスクロール・ピンチ操作を許可する。ボタンやリンク上から始まる操作、キャンセルされた操作、複数指、短いドラッグ、マウスのドラッグではキャラを切り替えない。
- 遷移中の追加スワイプは受け付けない。移動先は同じ詳細ページの処理で、所持・育成値を本人のDBから取得する。登録なしの閲覧も引き続き可能。

`tests/e2e/collection-swipe.spec.ts` はChromiumへタッチイベントを送り、前後移動・先頭末尾・誤操作防止・情報タブ操作・スマホ縦横の表示を確認する。DBへの変更や移行は不要。

2026-10-27に本番用ビルドと型チェックが成功し、操作4件に加えて登録なし閲覧・所持状態・収集同期の確認を含む8件が成功した。タッチ入力の再現と通常タップは独立したブラウザ状態で検証する。物理端末での確認は別途行う。
