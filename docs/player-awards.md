# 討伐ポイント・称号・バッジ

本番APIで完了した討伐成功の記録1件につき、本人へ100討伐ポイントを付与する。用途はプロフィールでの累計表示で、購入・交換・能力アップの処理は含めない。称号とバッジは同じマイルストーンで同時に獲得する。

| 条件 | バッジ | 称号 |
| --- | --- | --- |
| パートナーを1体獲得 | 最初のパートナー | 駆け出しの冒険者 |
| レイドを1回完了（成功／全滅） | はじめてのレイド | レイドの仲間 |
| 4学科のキャラを獲得 | 4学科コンプリート | 4学科の探究者 |
| 討伐成功1回 | 初討伐 | ドラグーン討伐者 |
| 討伐成功3回 | 討伐の達人 | レイドの勇士 |
| 討伐成功10回 | 討伐の英雄 | レイドの英雄 |

条件・表示名・ポイントは `src/lib/achievement-rules.ts` にまとめる。獲得済みの中で最も上位の称号をプロフィールの名前の下に表示し、「報酬・称号」タブでポイント、6種類の獲得状態・条件・進捗、最近10件のポイント履歴を確認できる。記録／報酬タブを開いている間は既存の記録APIの3秒更新で反映する。

## 付与と重複防止

- 収集はNFC／展示QRの獲得トランザクション内で判定する。4学科は既定の4学科IDの所持を数え、学科なし4体で代用しない。体験使用のキャラは収集に数えない。
- レイドは従来の `RaidResult` に記録される参加者が対象。回復役や体験参加も対象だが、最終演出中に来ただけで記録がない人は対象外。全滅や途中リセットに討伐ポイントは付けない。
- 完了記録・ポイント・称号／バッジと部屋の保存済みフラグは、同じDBトランザクションで保存する。途中で失敗した場合は全てロールバックし、再送で再試行できる。
- `RaidReward.raidResultId` のUNIQUEで1人1戦の100ポイントを一度だけ記録する。累計は台帳の合計を読み、クライアントからポイント量や任意ユーザーの付与を受け付けない。
- `PlayerAchievement` の `playerId + code` のUNIQUEで節目を一度だけ付与する。プレイヤー行をロックするため、収集と戦闘完了が同時でも競合しない。マイルストーンのコードはデータ互換性のため維持する。
- 部屋のリセット・再読み込みでポイントと称号は消えない。イベントの保存期限後の既存purgeでは、プレイヤーと一緒に外部キーのcascadeで削除する。
- プロフィールと `/api/profile/records` のGETは読み取りのみ。イベントが終了していても、保存済みのポイント・称号は本人の記録として参照できる。

## 既存記録への反映と配布

`202610280001_player_awards` は保存用の `RaidReward` と `PlayerAchievement` の追加のみ。既存のキャラ・Skill・所持・討伐結果を削除しない。今回の移行は専用ローカルDBにのみ適用済み。本番には未適用。

サーバー反映時は既存のDBバックアップを取得し、最新の統合版ソースと同じPrismaクライアント／マイグレーションで更新する。既存データを削除・初期化しない。

```powershell
npm run db:migrate
npm run db:generate
npx tsx scripts/backfill-player-awards.ts          # 検証のみ
npx tsx scripts/backfill-player-awards.ts --apply  # 既存記録から付与
```

既存の保存済み所持・完了した討伐記録だけを根拠に付与する。過去の獲得日時／完了日時を保存し、何度実行しても重複しない。`--event=イベントID` で対象を絞れる。バックフィルは自動起動には組み込んでいない。新たな獲得や戦闘完了でも、本人の未付与の保存済み記録を照合する。以前に削除・リセットされて記録が残っていない戦闘を推測して補わない。

## 必殺技欄の廃止

キャラ詳細のタブは「ステータス」「紹介」の2つにする。未実装の必殺技を利用可能に見せない。Skillテーブル・登録済みデータと既存APIの互換フィールドは保持する。攻撃・回復モーションは必殺技とは別で、引き続き同期レイドで使用する。

## 検証

条件の境界、異なる4学科、上位称号の表示を単体テストする。専用DBと本番起動では、実際のNFC獲得／レイド完了からの付与、20人分の報酬、再送・リセット・全滅・同時付与・バックフィル・ロールバック・削除・他人の報酬を取得できないことを検証する。プロフィールはスマホ縦横のはみ出しと10px以下の文字も確認する。

2026-10-28に本番ビルド・型チェック、全単体テスト131件、関連結合テスト13件が成功した。375×667・390×844・430×932・844×390でプロフィールの画面外へのはみ出しと10px以下の可視文字は0件。獲得済みのバッジを先に表示し、詳細はパネル内でスクロールする。本番DBには未反映。
