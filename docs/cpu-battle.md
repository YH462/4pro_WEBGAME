# CPU対戦の仮実装

未確定のキャラ・必殺技・バランスを後から差し替えるための、お試し対戦です。既存の単一Next.jsアプリ内で動作し、新しい通信サービスや戦闘用DBテーブルは追加しません。

- バトルメニュー `/battle` から12体のうち1体を選択。既存5体に加え、7体を明示的な仮キャラとして追加します。
- CPU対戦では未所持もお試し選択でき、対戦中はキャラのイラストを表示します。図鑑・ホームの未獲得シルエットと所持状態は変更しません。追加7体の姿は仮のロボットです。
- 自分とCPUを同じフィールドに表示します。CPUの次の行動・防御しない場合のダメージを確認してから、攻撃・防御・必殺を選びます。
- 1回の選択で両者の行動を確定します。自分の行動→CPUの反撃→次の選択の順で、移動・被弾・盾・ダメージ数値・HP変化を表示します。相打ちもある同時ターン制です。演出中1.5秒の連打は無効です。
- 勝利・敗北・引き分けの後は同じキャラで再戦、または選び直しができます。リロードで対戦はリセットされ、勝敗・報酬・育成は保存しません。
- 会場QRは `/battle/raid` のレイドプレビューへ進みます。既存の `/battle` QRも同じレイド画面へ案内します。

## 仮ルール

値は `src/lib/cpu-battle.ts` に集約しています。正式な必殺技やレイドの数値を確定するものではありません。

| 項目 | 仮設定 |
| --- | --- |
| CPU | デスドラグーン：HP180、攻撃30、防御20、チャージ50 |
| 通常攻撃 | 攻撃力 − 相手の防御×0.35、四捨五入、最低1ダメージ |
| 防御 | そのターンの被ダメージを0.35倍、四捨五入、最低1。攻撃はしない |
| 防御成功 | 実際に攻撃を受け止めた場合だけ、通常のチャージに加えてEP25を獲得。相手も防御ならボーナスなし |
| EP | 初期0、最大100。攻撃・防御の後にチャージ効率分を加算 |
| 未設定のチャージ効率 | CPU練習用に25を使用。マスタのNULLは書き換えない |
| 必殺 | EP100を消費。攻撃力を2.4倍としてダメージ計算。使用ターンはEPを回復しない |
| CPUの選択 | 攻撃→防御→必殺の3ターン周期。EP100なら必殺を優先。抽選はなく、予告と同じ行動を確実に実行 |
| 必殺後の隙 | CPUが必殺を使った直後の1ターンだけ、CPUへのダメージ1.5倍（通常の計算後に四捨五入）。そのターンにCPUは通常攻撃 |
| 決着 | どちらかのHP0で勝敗、同時KOまたは30ターン経過は引き分け |

## 仮キャラ

名前・見た目・数値は全て差し替え前提です。IDを維持してマスタを更新すれば、既存の所持参照を保ったまま調整できます。`seed` の再実行はスタッフの編集済みデータを上書きしないため、作成後の調整はDB側でも明示的に行います。

単体テストでは予告と実行の一致、防御のボーナス、隙の有効期間、勝敗に加え、攻撃連打だけでは初期キャラが負ける一方、12体すべてに勝てる行動手順があることを検証します。ブラウザでは両キャラ表示・CPU反撃・必殺を防いでの勝利・再戦・演出中の連打防止・所持データの非更新・5画面サイズを検証します。
